# Desktop

Shutdown Shortcut - Right-click on an empty area on your desktop. Select New>Shortcut
 - shutdown -a
 - shutdown -s -t 3600 // 1hour
 - shutdown -s -t 7200 // 2hour
 - shutdown -s -t 10800 // 3hour
